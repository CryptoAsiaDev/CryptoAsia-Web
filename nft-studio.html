Layers are drawn from the top of the list (back) to the bottom (front). Drag the handle to reorder. Drop images on a layer to add them. Click a trait to edit it. All images should be the same size, ideally transparent PNG.

COLLECTION

The seed decides which NFTs are made. The same seed and settings always give the same collection. Re-rolling makes a different collection, which needs a new payment to export.

METADATA

After you upload the images to IPFS or your host, put the folder link here. Each token will point to <link>/<number>.png.

Royalty and recipient go into collection.json (OpenSea contract-level metadata). Editing metadata never changes your paid version.
